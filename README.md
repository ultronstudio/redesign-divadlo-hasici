# Divadlo U Hasičů redesign

Směr:

- moderní divadelní web ve stejné rodině jako schválené redesigny VČD a Divadla Kalich,
- bez „AI landing page“ estetiky: žádné eyebrows, pill tlačítka, KPI bloky, ikonkové benefity, gradientové dekorace, glassmorphism ani generické marketingové slogany,
- klasický nesticky header, velký reálný divadelní obsah, jednoduché seznamy a přímá cesta program -> představení -> vstupenky,
- zachované barvy Divadla U Hasičů: tmavá hnědá / vínová, červená, oranžovo-zlatá, bílá a krémová,
- výrazně větší typografie a širší obsah při 100% zoomu,
- program je tabulkový/seznamový, repertoár typografický, ne sada generických karet,
- ticketing a praktické informace jsou obsahové bloky, ne SaaS feature cards,
- použity skutečné texty a kontaktní informace současného webu.

Použito:

- Bootstrap 5.3.8
- Bootstrap Icons 1.13.1
- Roboto + Merriweather
- vanilla JavaScript

Poznámka k obrázkům:

- lokální demo assety jsou výřezy ze screenshotů dodaných jako reference; při ostré realizaci je nahradit originálními zdrojovými fotografiemi divadla.
